# avito-like-api - training backend for students

A training REST API project: avito-like market app

## Quick Start

```bash
git clone https://github.com/aiinty/avito-like-api
cd avito-like-api

python -m venv .venv
pip install -r requirements.txt

copy .env.example .env

uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
